# Security reports and limitations

Do not post secrets, exploit credentials, private operator evidence or customer information in public issues. Use the upstream repository's GitHub security reporting route when available; if private reporting is unavailable, request a private contact route without including sensitive details. This candidate does not invent a security mailbox or response-time guarantee.

Include the affected source revision, minimal reproduction, expected authority boundary and observed result. Distinguish a reference adapter from a qualified host. See [SECURITY_MODEL.md](risk-fork/SECURITY_MODEL.md) and the [operational gates](risk-fork/managed-service/DEPLOYMENT_GATES.md).

The optional SDK inspector provides source/load checks within its stated controlled-process boundary. It does not prove authentic installation, immutable filesystem custody, complete ESM dependency capture, resistance to concurrent host tampering, or production isolation. A refusal after import cannot undo code that was already evaluated. Live provider activation remains disabled pending separate qualification.
